# Claude Code Tool Mapping

| Action skills request | Claude Code equivalent |
|-----------------------|------------------------|
| Dispatch a subagent | `Agent` or `Task` tool |
| Track tasks | `TodoWrite` or markdown checklist |
| Read file | `Read` |
| Write / Create file | `Write` |
| Edit file | `Edit` |
| Run shell command | `Bash` |
| Search code | `Grep`, `Glob` |
