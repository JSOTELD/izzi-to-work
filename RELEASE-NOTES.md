# Release Notes · Izzi to Work

## v1.0.0 (Initial Production Release)

Welcome to the initial production release of **Izzi to Work** (`v1.0.0`), a multi-harness agentic skills framework and engineering discipline suite built for modern AI coding agents across the global developer community.

### Highlights

- **Universal Multi-Harness Compatibility:**
  Natively compatible with Google Antigravity CLI/IDE (`agy`), Claude Code, Cursor, Codex, Gemini CLI, OpenCode (v1 & v2), Pi, Kimi, Devin, Hermes, and Muse.
- **Cross-Platform Polyglot Hooks:**
  `run-hook.cmd` polyglot bash/batch dispatcher, `session-start` multi-format context injector, and `garry-dustpan` lifecycle memory restoration (`Stop`, `PreCompact`, `PostCompact`).
- **25 Actionable Engineering Skills Across 5 Pillars:**
  1. **Context & Token Economy:** `using-izzi-to-work`, `context-checkpoint`, `auto-compact-dustpan`, `token-budget-guard`.
  2. **Testing, Database & Git Rigor:** `mutation-testing`, `lean-playwright-e2e`, `postgres-live-testing`, `zero-downtime-migrations`, `ci-failure-triage`, `git-rebase-conflict-resolver`.
  3. **Architecture, Finance & Security:** `financial-integrity`, `admin-console-patterns`, `idempotent-transactions`, `spec-driven-architecture`, `owasp-security-audit`, `secret-leak-sentinel`, `privacy-compliance`, `api-contract-and-error-resilience`.
  4. **UI/UX, Anti-Slop & Design:** `anti-slop-pruner`, `editorial-luxury-design`, `ux-heuristic-audit`, `responsive-pixel-police`, `dependency-diet`.
  5. **Multi-Agent Governance:** `blind-voting-board`, `zero-trust-squad`.
- **Automated Verification Suite:**
  End-to-end manifest validation, skill byte size checks (`< 20,000 bytes`), 12-manifest version synchronization (`bump-version.sh`), and platform tool mappings.
