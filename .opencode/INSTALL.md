# Installing Izzi to Work for OpenCode

Izzi to Work is fully compatible with OpenCode v1 and v2.

## Installation

Add the plugin to your OpenCode configuration in `opencode.json`:

```json
{
  "plugins": [
    "https://github.com/JSOTELD/izzi-to-work.git"
  ]
}
```

Or clone directly into your workspace plugins directory:

```bash
git clone https://github.com/JSOTELD/izzi-to-work.git .opencode/plugins/izzi-to-work
```
